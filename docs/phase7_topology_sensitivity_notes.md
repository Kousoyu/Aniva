# Phase 7.5: Topology Sensitivity — 分析笔记

> **日期**: 2026-05-03
> **状态**: 探索性分析，n=11 样本
> **依赖**: Phase 7.4 多 seed 120k 结果

---

## 1. 分析目的

Phase 7.4 证明了 11/11 seed 均表现出非零的 history-dependent structural divergence，但幅度不同：

```
significant: 1/11  (seed=42)
emerging:    7/11  (seeds 2,4,5,77,99,123,999)
weak:        3/11  (seeds 1,3,10)
```

Phase 7.5 的目标是初步探索**初始拓扑的哪些特征可能解释这种差异**。

---

## 2. 方法

- 对每个 seed 用相同 `AnivaConfig` 重建初始 `LifeCore`，提取 28 个拓扑特征
- 计算每个特征与 `delta_weight_l1` 的 Pearson 相关系数
- **不运行任何模拟**，仅分析初始网络结构

---

## 3. 结果

### 3.1 相关性排名（|r| > 0.4）

| Feature | Pearson r | 方向 |
|---|---|---|
| L_to_R_connection_count | -0.59 | 负 |
| time_constant_std | +0.59 | 正 |
| time_constant_mean | +0.52 | 正 |
| R_affected_count | -0.51 | 负 |
| threshold_std | -0.50 | 负 |
| R_to_L_connection_count | -0.46 | 负 |
| out_degree_std | -0.46 | 负 |
| L_affected_count | -0.43 | 负 |

### 3.2 可能的方向性解释

**L_to_R_connection_count (r = -0.59)**
种子初始有更多从左到右的连接 → 分叉反而更小。
一种可能的解释：L→R 通路已经很强时，L 刺激的效应能更直接传递到右半球，
后续 R 刺激的"反向雕刻"空间更小。反之，如果 L→R 通路初始稀疏，
顺序差异就有更多结构可改变。

**time_constant_std (r = +0.59)**
单元时间常数更不均匀 → 分叉更大。
这比较直观：时间常数异质性意味着不同单元对同一刺激的响应速度不同，
给顺序依赖提供了更大的"表达空间"。

**time_constant_mean (r = +0.52)**
平均时间常数更大 → 分叉更大。
较大的时间常数意味着激活回落更慢，刺激效应持续时间更长，加强了顺序的作用。

**R_affected_count (r = -0.51)**
R 刺激影响更多单元 → 分叉更小。
与 L→R 连接数量的负相关可能有关联：如果 R 区域本身就大，意味着
L 和 R 区域的空间重叠更大，顺序的差异性效应被稀释。

---

## 4. 关键限制

### 4.1 样本量 n=11

这是最重要的限制。n=11 时，Pearson r 的统计显著性阈值（α=0.05, 双尾）约为 **|r| > 0.602**。

**当前没有任何特征达到统计显著。**

这意味着：
- 观察到的相关性是**方向性信号**，不是**确定结论**
- 相关性最强的两个特征（|r| ≈ 0.59）接近但未达到临界值
- 所有结论都应该被理解为"值得后续用更大样本验证的初步发现"

### 4.2 多重比较

测试了 28 个特征，若不做多重比较校正，仅靠随机也有 ~1.4 个特征期望达到 |r| > 0.5。当前 4 个特征的 |r| > 0.5，比随机期望多，但不足以排除部分为假阳性。

---

## 5. 结论

在 n=11 的限制下，以下特征表现出**可指引后续验证的方向性信号**：

1. **区域间连接数量**（L→R, R→L）：与分叉幅度负相关
2. **时间常数异质性**（std, mean）：与分叉幅度正相关
3. **刺激影响范围**（L/R affected count）：与分叉幅度负相关

这些信号的共同点是：它们都指向**网络内部的连通性平衡和动力学异质性**，
而非简单的"空间不对称"或"E/I 比例"。

**这不是结论，这是一个研究方向的起点。**

下一步若想确认这些信号，需要：
- 扩大样本量（n ≥ 30）
- 或用主动操控实验：固定其他参数，只改变 time_constant_std，看分叉是否系统变化
