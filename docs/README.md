## What the current public evidence says

- Phase 9D established that ordered event history can sediment into structural
  change through the tagging/capture pipeline.
- Phase 10E tested whether historical context h[u] predicts tag formation.
- Phase 10F showed that the support of tag formation is trace[src] × phi[tgt]
  support geometry, and that current h[u] is not a direct upstream driver.
