# Security Policy

## Supported research scope

This repository is an experimental research prototype. Please report issues that
could affect safety, correctness, or reproducibility of the codebase.

## What to report

- leaked secrets or credentials
- code execution or dependency issues
- incorrect experiment results caused by implementation bugs
- unexpected behavior in diagnostics or data capture

## What not to report here

- claims about consciousness, personhood, or digital life
- general feature requests unrelated to the research code

## Contact

Open a GitHub issue for non-sensitive reports.
For sensitive security concerns, contact the maintainers privately if a contact
channel is available.
